Component / ToolRole in Your Learning 

React + Express + MySQL: The core 3-tier app. 
Simple enough to build quickly, complex enough to mirror real enterprise architecture.

Docker & Docker Compose: Packaging the frontend, backend, and database into independent containers and networking them locally.

GitHub Actions (CI/CD): Automating code linting, building Docker images, and pushing them to a container registry (e.g., Docker Hub or AWS ECR).

Terraform (IaC): Provisioning cloud infrastructure (like an AWS EKS cluster or EC2 instances + AWS RDS MySQL) automatically via code.

Kubernetes (K8s): Deploying and managing your containers with Deployment manifests, Services, Ingress Controllers, ConfigMaps, and Secrets.

Prometheus & Grafana: Scraping metrics from your backend (e.g., CPU, HTTP request counts, DB latency) and visualizing them on custom dashboards.

PHASE 5: END-TO-END DATA PERSISTENCE & VERIFICATION FLOW
==================================================================================================================

  [ 1. User Interface ]
  User enters data in React UI at http://localhost:3000
          │
          ▼
  [ 2. HTTP POST Request ]
  React triggers API write request to http://localhost:8010/api/services
          │
          ▼
  [ 3. Local Tunnel Entry ]
  Request hits Port 8010 tunnel -> forwarded via K8s backend-service
          │
          ▼
  [ 4. Node.js Execution ]
  Backend Pod receives payload -> Executes SQL INSERT INTO HEALTH_DB
          │
          ▼
  [ 5. MySQL Database Write ]
  MySQL Pod processes transaction and stores record in persistent volume
          │
          ▼
  [ 6. Data Verification ]
  Navigating to http://localhost:8010/api/services retrieves JSON payload:
  [ { "id": 1, "service_name": "New Added Service", "status": "active" } ]
